# Weather photography backgrounds

Seven decorative, AI-generated photographic landscapes, created with the built-in imagegen tool. They illustrate weather conditions, not the actual selected city. Original portrait PNGs are bundled locally by Vite; no external image service is needed at runtime.

Files: clear-day.png, clear-night.png, cloudy.png, rain.png, thunderstorm.png, snow.png, fog.png.

The exact generation prompts are in prompts.json. Manrope is self-hosted through @fontsource-variable/manrope (OFL-1.1), imported only by the weather panel.

Replace any PNG with your own licensed photograph using the same filename. Missing files and load errors fall back to a condition-specific gradient. Keep the foreground overlay in place for readable text.
